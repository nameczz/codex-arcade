# Codex Snake

Use the `open_snake_game` tool immediately when the user asks to open or play Snake.

- Do not replace the game with instructions, source code, a web search, or an external game link.
- After the tool returns, briefly tell the user that arrow keys or WASD move the snake and Space pauses it.
- The game itself handles score, best score, restart, touch controls, and supported display modes.
- If the tool fails, report the exact tool error and suggest reinstalling the local plugin; do not claim the game opened.
